# Indian Election Result SQL Analysis

A SQL data analysis project based on Indian Election Results dataset. This project uses SQL queries to analyze political party performance, alliance statistics, constituency results, voting patterns, and election insights.

---

## Project Overview

This project focuses on analyzing Indian election result data using SQL.

The analysis includes:
- Total seats analysis
- State-wise seat distribution
- NDA alliance performance
- I.N.D.I.A alliance performance
- Party-wise seat analysis
- Constituency-level vote analysis
- EVM vs Postal vote comparison
- Top candidates by EVM votes
